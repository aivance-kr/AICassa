## 1. 부가세 자동계산 (`장부입력.frm` → `cbo비고_Change`)

부가세는 사용자 입력이 아니라 **금액(공급가액) + 증빙유형(비고)** 으로 자동 산출한다.

```
IF 증빙유형 IN (계산서, 간이영수증, 기타):
    부가세 = 0
ELSE:  # 세금계산서, 신용카드, 현금영수증
    부가세 = 금액 × 0.1
```

- 저장 시 정수화: `부가세 = Int(부가세)` (소수점 버림)
- 검증: 증빙유형이 "계산서"인데 부가세 ≠ 0 이면 저장 거부
  ("계산서매입은 부가세가 0 이어야 합니다.")

> **PHP 이식**: `VatCalculatorService::calc($amount, $evidenceType): int`
> 면세 증빙(계산서/간이영수증/기타) → 0, 과세 증빙 → `intval($amount * 0.1)`

## 2. 거래(전표) 저장 & 컬럼 매핑 (`장부입력.frm` → `cmd기록_Click`)

### 2.1 전표구분(거래유형) 4종
| 라디오 | str전표구분 | 장부 기록 위치 |
|---|---|---|
| 수입 | `수입` | 수입 금액/부가세 |
| 비용 | `비용` | 비용 금액/부가세 |
| 자산_구입 | `자산_구입` | 자산 금액/부가세 (양수) + **자산대장에도 등록** |
| 자산_매각 | `자산_매각` | 자산 금액 **× -1** (음수) + 자산대장 처분일/금액 갱신 |

### 2.2 장부(shtMain) 컬럼 매핑
| col | 내용 | col | 내용 |
|---|---|---|---|
| 1 | 일자(date) | 8 | 비용 부가세 |
| 2 | 계정과목 | 9 | 자산 금액 (매각시 음수) |
| 3 | 거래내용(자산명) | 10 | 자산 부가세 |
| 4 | 거래처(상호) | 11 | 비고(증빙유형) |
| 5 | 수입 금액 | 12 | (감가상각) 자산명 |
| 6 | 수입 부가세 | 23 | 전표구분 |
| 7 | 비용 금액 | 24 | `=YEAR(일자)` (귀속연도) |

### 2.3 입력 검증
- 날짜: `IsDate()` 유효성
- 금액: `IsNumeric()` 필수
- 자산_구입: 자산명(거래내용) 필수 + **자산명 중복 불가**
- 자산_구입 시 계정과목="건물 및 구축물" → 감가상각방법 자동 `정액법` 설정

> **PHP 이식**: `ledger_entries`에 `entry_type`(수입/비용/자산_구입/자산_매각),
> `income_amount/income_vat`, `expense_amount/expense_vat`,
> `asset_amount/asset_vat`, `fiscal_year` 컬럼. 자산 매각은 asset_amount 음수 저장.

## 3. 감가상각비 계산 (`mModules` → `sQuery연도별감가상각정보`)

### 3.1 참조표 조회
- **내용연수** (`fGet내용연수`): 업종코드 → `표준산업분류연계표` 시트 26번째 열에서 조회
- **상각률** (`fGet상각률`): `내용연수별상각률` 시트에서 조회
  - 정액법 → 2번째 열, 정률법 → 3번째 열, key = 내용연수(문자열)
  - 미존재 시 -100 반환(오류값)

### 3.2 정액법 (定額法)
```
계산한도액 = Int(취득금액 × 상각률)

# 처분한 해의 월할상각
IF 조회연도 == 처분연도:
    IF 처분월 == 12:  한도액 = 계산한도액
    ELSE:            한도액 = Int(계산한도액 / 12 × 처분월)
ELSE:
    한도액 = 계산한도액

한도액 = MIN(한도액, 직전장부가액)

# 비망가액(memorandum value) 1,000원 유지
IF (직전장부가액 - 한도액) <= 1000:
    한도액 = 한도액 - (1000 - (직전장부가액 - 한도액))
```

### 3.3 정률법 (定率法)
```
잔존가액 = Int(취득금액 / 20)          # 취득금액의 5%
계산한도액 = Int(직전장부가액 × 상각률)   # 정액법과 달리 '장부가액' 기준

# 처분한 해의 월할상각 (정액법과 동일 규칙)
IF 조회연도 == 처분연도:
    IF 처분월 == 12:  한도액 = 계산한도액
    ELSE:            한도액 = Int(계산한도액 / 12 × 처분월)
ELSE:
    한도액 = 계산한도액

# 잔존가액 이하로 내려가면 비망가액 1,000원만 남김
IF (직전장부가액 - 한도액) <= 잔존가액:
    한도액 = 직전장부가액 - 1000
```

### 3.4 취득연도 월할상각 (취득한 해)
```
계산한도액 = Int(취득금액 × 상각률)
IF 취득월 == 1:  한도액 = 계산한도액
ELSE:           한도액 = Int(계산한도액 / 12 × (12 - 취득월 + 1))   # 취득월부터 12월까지 개월수
```

### 3.5 핵심 개념
- **장부가액(미상각잔액)** = 최초취득가액 − 감가상각누계액
- **직전장부가액** = 직전 감가상각비 전표의 장부가액
- 처분연도 이후에 감가상각비 전표가 있으면 처분 전표 입력 불가 (`fGetMinYearAfterColl감가상각비`)
- 처분일은 취득일보다 빠를 수 없음

> **PHP 이식**: `DepreciationService::compute($asset, $year)`.
> 정액=취득금액 기준, 정률=직전장부가액 기준. 월할상각(취득/처분연도), 비망가액 1,000원,
> 정률 잔존가액=취득금액/20 규칙을 그대로 구현. 모든 중간계산은 `intval()`(원 단위 버림).

## 4. 매출원가 & 재고 (`재고입력.frm`)

간편장부는 재고 입력을 별도로 받아 매출원가를 계산한다(제조업 여부에 따라 분기).

```
# 상품(도소매)
상품 매출원가 = 기초상품재고 + 당기상품매입액 - 기말상품재고

# 재료(제조업)
재료비 = 기초재료재고 + 당기재료매입액 - 기말재료재고
```

- 연도별 재고를 `연도data` 시트에 누적 저장 (당해 기초 = 전기 기말 자동 연계)
- 값은 정수화 `Int(x)`

> **PHP 이식**: `inventories` 테이블 (business_id, 귀속연도, 상품기초/기말, 재료기초/기말).
> 당기매입액은 `ledger_entries`의 상품매입/재료매입 계정 합계.

## 5. 소득금액 계산 구조 (신고서식)

프로그램의 신고서식 3종은 위 값들의 집계로 생성된다.

```
총수입금액 = Σ(수입 계정 금액)                     # 매출 + 기타수입
필요경비   = 당기 매출원가/재료비
           + Σ(비용 계정 금액: 급료·임차료·이자·감가상각비 등)
소득금액   = 총수입금액 - 필요경비
```

- **간편장부 소득금액계산서**: 총수입 / 필요경비 / 소득금액 요약
- **총수입금액 및 필요경비명세서**: 계정과목별 상세 명세
- **감가상각비 조정명세서(정률법/정액법)**: 3장의 감가상각 결과 반영

> **PHP 이식**: `TaxFormService`가 `SummaryService`(계정별 집계) +
> `DepreciationService` + `inventories`를 조합해 서식 데이터 생성.
> 귀속연도별 서식 템플릿 버전 관리 필요.

## 6. 집계/정렬 부가 규칙
- 장부는 저장 시마다 **일자→계정과목→거래내용** 순으로 자동 정렬 (`sSortMain`)
- 영업현황표: 월별·분기별로 수입/비용/자산증감의 금액·부가세 합산 (`분석`·`통계` 시트)
- 거래처: 상호·사업자번호 중복 검사 시 사업자번호는 하이픈(-) 제거 후 비교

## 7. 이식 시 주의 (검증 포인트)
1. **정수 절사**: VBA `Int()`는 원 단위 버림. PHP `intval()`/`floor()`로 일치시킬 것
2. **부가세 면세 증빙 3종**(계산서·간이영수증·기타)은 반드시 0
3. **정률법은 직전장부가액 기준**, 정액법은 취득금액 기준 — 혼동 금지
4. **비망가액 1,000원**은 자산이 완전상각되지 않도록 남기는 장부상 최소가액
5. **월할상각**: 취득연도는 취득월~12월, 처분연도는 1월~처분월 (개월수 비례)
6. 위 규칙은 **2023 귀속 기준** 프로그램에서 추출 → 최신 세법과 대조 검증 필요
