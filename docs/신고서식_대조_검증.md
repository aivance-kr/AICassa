# 종합소득세 신고서식 대조·검증 문서

> 국세청 공식 서식(간편장부 작성 프로그램 v3.4 내장 시트)과 본 시스템의
> 신고서식 출력을 **필드 단위로 대조**하고, 계산 규칙·가정·갭을 정리한다.

---

## 0. 목적과 한계 (반드시 읽을 것)

- 본 문서는 **개발 측 자체 대조**이며, **세법 준수의 법적 검증이 아니다.**
- **세법 실무 정확성은 반드시 세무사(전문가) 또는 홈택스 전자신고 대조로 확인**해야 한다.
  본 시스템은 참고·기장 보조 도구이며, 최종 신고 책임은 납세자/세무대리인에게 있다.
- **픽셀 단위 서식 일치**는 국세청 공식 서식(HWP/PDF) 원본이 필요하다. 현재 시스템은
  아래 대조표대로 **필드·계산 매핑은 일치**하나, 인쇄 레이아웃은 근사(표 형태)다.
- 대조 기준: 2023 귀속(프로그램 v3.4). 서식은 매년 개정되므로 `Config\TaxForm`
  버전 관리와 함께 연도별 재검증 필요.

## 1. 간편장부 소득금액계산서 (별지 제82호서식)

| 공식 필드 | 계산식 | 본 시스템 | 상태 |
|---|---|---|---|
| ⑪ 장부상 수입금액 | 부표 ⑬ | `total_revenue` | ✅ 구현 |
| ⑫ 수입금액에서 제외할 금액 | 세무조정 | 0 | ⚠️ 미구현(세무조정) |
| ⑬ 수입금액에 가산할 금액 | 세무조정 | 0 | ⚠️ 미구현(세무조정) |
| ⑭ 세무조정 후 수입금액 | ⑪-⑫+⑬ | = ⑪ | ✅ (조정 0 가정) |
| ⑮ 장부상 필요경비 | 부표 ㊶ | `necessary_expense` | ✅ 구현 |
| ⑯ 필요경비에서 제외할 금액 | 세무조정 | 0 | ⚠️ 미구현(세무조정) |
| ⑰ 필요경비에 가산할 금액 | 세무조정 | 0 | ⚠️ 미구현(세무조정) |
| ⑱ 세무조정 후 필요경비 | ⑮-⑯+⑰ | = ⑮ | ✅ (조정 0 가정) |
| ⑲ 차가감 소득금액 | ⑭-⑱ | `income_amount` | ✅ 구현 |
| ⑳ 기부금 한도초과액 | | 0 | ⚠️ 미구현 |
| ㉑ 기부금이월액 중 필요경비산입액 | | 0 | ⚠️ 미구현 |
| ㉒ 당해연도 소득금액 | ⑲+⑳-㉑ | = ⑲ | ✅ (기부금조정 0 가정) |

**결론**: 세무조정·기부금 조정이 **없는 표준 케이스에서는 본 시스템의 `income_amount`
= ㉒ 당해연도 소득금액과 일치**한다. 세무조정/기부금 한도초과가 있는 사업자는
현재 미지원 → 해당 항목 입력·계산 기능 추가 필요(세무사 검토 항목).

### 헤더(인적사항) 필드
①주소지 ②전화번호 ③성명 ④생년월일 ⑤소재지 ⑥업종 ⑦주업종코드
⑧사업자등록번호 ⑩소득종류
- 본 시스템 `businesses`에 대응 컬럼 보유(owner_name·birth_date·address·phone·
  industry_name·industry_code·biz_reg_no·income_type). **출력에는 상호·사업자번호만
  노출 중** → 전체 인적사항 출력 반영 필요(작업 항목).

## 2. 총수입금액 및 필요경비명세서 (별지 제82호서식 부표)

공식 필드 번호 → 본 시스템 계정과목 매핑(원본 시트 그대로):

| 공식 필드 | 항목 | 본 시스템 매핑 | 상태 |
|---|---|---|---|
| ⑪ 매출액 | 수입 | `매출` 계정 합 | ✅ |
| ⑫ 기타 | 수입 | `기타(수입)` 계정 합 | ✅ |
| ⑬ 수입금액합계 (⑪+⑫) | | `total_revenue` | ✅ |
| ⑭ 기초 재고액(상품) | 매출원가 | `inventory.goods_begin` | ✅ |
| ⑮ 당기 상품매입액 | | `상품매입` 계정 합 | ✅ |
| ⑯ 기말 재고액(상품) | | `inventory.goods_end` | ✅ |
| ⑰ 매출원가 (⑭+⑮-⑯) | | `goods_cogs` | ✅ |
| ⑱ 기초 재고액(재료) | 제조 재료비 | `inventory.materials_begin` | ✅ |
| ⑲ 당기 재료매입액 | | `재료매입` 계정 합 | ✅ |
| ⑳ 기말 재고액(재료) | | `inventory.materials_end` | ✅ |
| ㉑ 당기 재료비 (⑱+⑲-⑳) | | `materials_cost` | ✅ |
| ㉒ 노무비 | 제조 | `제조노무비` 계정 합 | 🔶 데이터有, 출력 세분화 필요 |
| ㉓ 경비 | 제조 | `제조경비` 계정 합 | 🔶 데이터有, 출력 세분화 필요 |
| ㉔ 당기제조비용 (㉑+㉒+㉓) | | 계산 필요 | ⚠️ 출력 미집계 |
| ㉕~㊴ 일반관리비 등 | 급료·제세공과금·임차료·지급이자·기업업무추진비·기부금·감가상각비·차량유지비·지급수수료·소모품비·복리후생비·운반비·광고선전비·여비교통비·기타 | 동일 계정과목 합 | ✅ 계정별 합 출력 |
| ㊵ 일반관리비 등 계 (㉕~㊴) | | 계산 필요 | 🔶 소계 별도표시 필요 |
| ㊶ 필요경비 합계 (⑰+㊵) | | `necessary_expense` | ✅ (제조업은 ㉔ 포함 재검토) |

**갭**: 제조업 사업장의 **제조비용 세부(㉒㉓㉔)** 와 **일반관리비 소계(㊵)** 를
현재 출력에서 별도 라인으로 세분화하지 않음. 계정 데이터는 모두 존재하므로
출력 구조만 공식 번호 체계에 맞춰 재배치하면 픽셀 근접 가능.
**제조업 필요경비 합계식(㊶=⑰+㊵) vs 비제조업** 처리는 세무사 확인 항목.

## 3. 감가상각비 조정명세서 (정률법/정액법)

공식 서식은 자산별 상세 항목 (1)종류 (2)자산명 (3)취득일 (4)내용연수
(5)기말현재액 (6)감가상각누계액 (7)미상각잔액 … (상각범위·시부인 등) 다수 필드.

| 본 시스템 출력 | 공식 대응 | 상태 |
|---|---|---|
| 자산명 | (2) | ✅ |
| 상각방법 | 서식 종류(정률/정액) | ✅ |
| 취득금액 | 취득가액 | ✅ |
| 당기 감가상각비 | 당기상각액 | ✅ |
| 감가상각누계액 | (6) | ✅ |
| 기말 장부가액 | 미상각잔액 | ✅ |

**갭**: 공식 조정명세서의 **상각범위액 계산·시부인(부인액/손금산입) 상세 라인**은
미구현. 본 시스템은 **당기 감가상각비(한도액)** 산출까지 제공(계산 규칙은 §4 검증).
상세 조정명세서 서식은 후속 작업 + 세무사 검토 항목.

## 4. 계산 규칙 검증 (원본 VBA 명세 대조)

`docs/간편장부_계산식명세.md`(VBA 역설계)와 본 시스템 구현 대조 결과:

| 규칙 | 원본 | 구현 | 테스트 | 일치 |
|---|---|---|---|---|
| 부가세 | 과세증빙 `Int(금액×0.1)`, 면세 0 | `VatCalculatorService` | ✅ | ✅ |
| 매출원가 | 기초+당기매입−기말 | `TaxFormService` | ✅ | ✅ |
| 감가상각(정액) | `Int(취득금액×상각률)` | `DepreciationService` | ✅ | ✅ |
| 감가상각(정률) | `Int(직전장부가액×상각률)` | `DepreciationService` | ✅ | ✅ |
| 월할상각 | 취득(13−취득월)/12, 처분 처분월/12 | 구현 | ✅ | ✅ |
| 비망가액 | 1,000원 유지 | 구현 | ✅ | ✅ |
| 소득금액 | 총수입−필요경비(세무조정 전) | 구현(⑲/㉒) | ✅ | ✅(조정 0) |

**계산 로직은 원본 프로그램과 일치**(단위 테스트로 고정). 단, 이는 프로그램 재현
정확성이며 **현행 세법 부합 여부는 세무사 확인 필요**.

## 5. 알려진 갭 · 미구현 (세무사 검토 대상)

1. **세무조정**(수입/필요경비 가산·제외 ⑫⑬⑯⑰) 미구현 → 0 가정
2. **기부금 한도초과·이월**(⑳㉑) 미구현
3. **제조비용 세부(㉒㉓㉔)·일반관리비 소계(㊵)** 출력 세분화 미완
4. 감가상각비 **조정명세서 상세(상각범위·시부인)** 미구현
5. **간편장부대상자 판정**(직전연도 수입금액 기준, 전문직 제외) 미구현
6. **결손금 이월공제**(15년) 미구현
7. **소규모사업자 무기장 가산세**(산출세액 20%) 안내 미구현
8. 자산 구입 시 **부가세**는 현재 0 처리(증빙유형 미수집) — 원본은 비고 기반 계산
9. 서식 인적사항 전체 항목 출력 미반영(상호·사업자번호만)

## 6. 세무사/홈택스 확인 필요 체크리스트

- [ ] 소득금액계산서 ⑪~㉒ 라인별 값이 홈택스 계산과 일치하는가
- [ ] 부표 ㊶ 필요경비 합계(제조업/비제조업) 산식
- [ ] 감가상각 상각률·비망가액·월할 규칙의 현행 세법 부합
- [ ] 기업업무추진비·기부금 등 **한도 규정** 반영 필요 여부
- [ ] 귀속연도별 서식 개정 반영(`Config\TaxForm` 버전 갱신)
- [ ] 실제 서식(HWP/PDF)과 인쇄 레이아웃 대조

## 7. 픽셀 일치 관련 결론

- **필드·계산 매핑**: 위 대조표대로 표준 케이스 일치 확인.
- **인쇄 레이아웃**: 현재 표 형태 근사. 완전 일치는 국세청 공식 서식 파일 확보 후
  §1~3 필드 번호 체계에 맞춰 재배치 필요(별도 작업).
- 권장: 실제 신고는 **홈택스 전자신고** 사용, 본 시스템 출력은 **기장·검토·보관용**.
