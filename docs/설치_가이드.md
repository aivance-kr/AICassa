# AICassa 설치 가이드

간편장부 웹 ERP(**CodeIgniter 4** 기반 Admin + 세법 파라미터 운영자 콘솔)를 로컬/서버에 설치하는 절차다.
도메인·설계 문서는 [`간편장부_웹ERP_분석설계.md`](간편장부_웹ERP_분석설계.md), 배포는 [`../README.md`](../README.md#배포-deployment) 참조.

---

## 1. 요구사항

| 항목 | 버전/조건 |
|---|---|
| PHP | **8.4 이상** (`composer.json` `require: php ^8.4`) |
| Composer | 2.x |
| 데이터베이스 | MySQL 5.7+ / MariaDB 10.3+ (기본 드라이버 `MySQLi`) |
| 웹서버 | Apache / Nginx, 또는 개발용 `php spark serve` |

### 필수 PHP 확장
- `intl`, `mbstring`, `json`, `mysqlnd` — CodeIgniter 4 필수
- `gd`, `zip`, `xml` — PhpSpreadsheet(엑셀 입출력, 간편장부 핵심 기능)
- `curl` — Anthropic AI 연동(선택 기능) 사용 시

확장 설치 확인:
```bash
php -m | grep -iE "intl|mbstring|mysqlnd|gd|zip|curl"
```

> **⚠️ Windows 환경**: 코드 편집은 어디서든 가능하나 **실행·마이그레이션·테스트·정적분석은 WSL(Ubuntu)** 에서 한다. Windows 체크아웃에는 PHP·Composer가 없다. 상세는 [CLAUDE.md](../CLAUDE.md#로컬-검증은-wsl-클론에서-실행-ci-왕복-예방) 참조.

## 2. 설치 절차

### 2-1. 소스 내려받기
```bash
git clone https://github.com/aivance-kr/AICassa.git
cd AICassa
```

### 2-2. 의존성 설치
```bash
composer install
```
> 운영 서버는 개발 의존성을 제외한다: `composer install --no-dev --optimize-autoloader`

### 2-3. 환경설정 파일 생성
```bash
cp env .env
```

### 2-4. `.env` 편집
아래 항목의 주석(`#`)을 해제하고 값을 채운다.

```dotenv
#--- 환경 ---
CI_ENVIRONMENT = development          # 운영은 production

#--- 앱 ---
app.baseURL = 'http://localhost:8080/'

#--- 데이터베이스 ---
database.default.hostname = localhost
database.default.database = aicassa
database.default.username = root
database.default.password =
database.default.DBDriver = MySQLi
database.default.port = 3306
```

DB는 사전에 생성해 둔다:
```sql
CREATE DATABASE aicassa CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2-5. 암호화 키 생성
세션·Shield 인증에 사용할 암호화 키를 `.env`에 자동 기록한다.
```bash
php spark key:generate
```

### 2-6. 마이그레이션 실행
```bash
php spark migrate --all
```
> **`--all` 필수.** 그냥 `php spark migrate`는 Shield의 `users` 테이블이 먼저 생성되지 않아 FK 제약 오류가 난다. `--all`은 Shield를 포함한 모든 네임스페이스 마이그레이션을 순서대로 적용한다.

### 2-7. 참조데이터 시딩
감가상각률표·업종코드·연도별 세법 파라미터 등 계산에 필요한 기준 데이터를 넣는다.
```bash
php spark db:seed ReferenceDataSeeder
```
> 이 시더는 **자동 실행되지 않는다.** 최초 설치와 참조데이터 개정 시 수동으로 한 번 실행한다. 세법 버전 관리 규칙은 [README](../README.md#개정세법-버전-관리-tax-rule-versioning) 참조.

### 2-8. 관리자(Shield) 계정 생성
Admin 로그인에 쓸 사용자를 만든다.
```bash
php spark shield:user create
```
프롬프트에 따라 사용자명·이메일·비밀번호를 입력한다.

### 2-9. 쓰기 권한 (서버 배포 시)
웹서버 사용자가 `writable/`에 쓸 수 있어야 한다.
```bash
chmod -R 775 writable/
# 필요 시 소유자 조정: chown -R www-data:www-data writable/
```

## 3. 실행

### 개발 서버
```bash
php spark serve
```
브라우저에서 `http://localhost:8080/` 접속.

### 웹서버(운영)
문서 루트를 반드시 **`public/`** 폴더로 지정한다(프로젝트 루트 지정 금지 — 소스 노출). Apache는 `public/.htaccess`, Nginx는 `try_files`로 `index.php` 라우팅을 구성한다.

## 4. 선택 설정

### 4-1. AI 업무효율화(Anthropic Claude)
계정과목 자동분류·영수증 판독·자연어 검색·엑셀 매핑 등 AI 기능을 켜려면 `.env`에 API 키를 넣는다.
```dotenv
ANTHROPIC_API_KEY = your-anthropic-api-key
ANTHROPIC_MODEL   = claude-sonnet-5      # 선택, 기본 claude-sonnet-5
```
> 키를 넣지 않아도 각 기능은 **비-AI 폴백(이력·규칙·검색)** 으로 동작한다. AI 키 없이 개발·테스트 가능. 기능 목록은 [README](../README.md#ai-업무효율화-기능-epic-20) 참조.

### 4-2. AI 레이트 리밋
유료 LLM 호출 남용을 막는 사용자 단위 스로틀. 무배포로 `.env`에서 조정한다.
```dotenv
ai.rateLimit.enabled  = true    # 기본 true
ai.rateLimit.capacity = 20      # 기본 20
ai.rateLimit.seconds  = 60      # 기본 60 → 분당 20회
```
> `ANTHROPIC_API_KEY` 미설정 시 외부 호출이 없으므로 레이트 리밋은 적용되지 않는다.

### 4-3. 세법 파라미터 운영자 콘솔
사업장 Admin과 **별도**인 운영자 로그인. `.env`에 계정을 지정한다.
```dotenv
operator.id       = admin
operator.password = change-this-strong-password    # 평문 또는 password_hash() bcrypt 해시
```
> 비밀번호가 `$2y$`로 시작하면 bcrypt 해시로 간주해 `password_verify`로 검증한다.

## 5. 설치 검증

```bash
composer check        # CS Fixer → PHPStan(L6) → PHPUnit — 전체 게이트
```
개별 실행:
```bash
composer test         # PHPUnit
composer analyse      # PHPStan 레벨 6
composer cs           # PHP CS Fixer 검사(dry-run)
php spark routes      # 라우트 목록 확인
```

## 6. 트러블슈팅

| 증상 | 원인 · 해결 |
|---|---|
| 마이그레이션 FK 오류(`users` 참조 실패) | `php spark migrate` 대신 **`php spark migrate --all`** 사용(2-6). |
| 계정과목·상각률이 비어 있음 | `ReferenceDataSeeder` 미실행 → `php spark db:seed ReferenceDataSeeder`(2-7). |
| 로그인 불가 / 세션 오류 | 암호화 키 미생성 → `php spark key:generate`(2-5). |
| 화면 500 / `writable` 쓰기 실패 | `writable/` 권한 부여(2-9). |
| 엑셀 업로드·다운로드 실패 | `gd`·`zip` 확장 미설치 → PHP 확장 설치 후 웹서버 재시작. |
| AI 기능 무응답인데 오류는 없음 | `ANTHROPIC_API_KEY` 미설정 → 비-AI 폴백으로 정상. 키 설정 시 AI 활성화. |
| 정적 자원 404 / URL에 `index.php` 노출 | 웹서버 문서 루트가 `public/`이 아님(3장). |
