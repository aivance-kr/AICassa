# 간편장부 웹 ERP 분석·설계 문서

> 국세청 「간편장부 작성 프로그램 v3.4」(Excel+VBA)와 사용자 설명서(62p),
> 국세청 표준 간편장부 엑셀 서식을 분석하여 **다중 사용자(SaaS) 웹 ERP**로
> 재구축하기 위한 요구사항·데이터 모델·아키텍처 설계 문서.
> 대상 스택: PHP CodeIgniter 4 (프로젝트 `CLAUDE.md` 기준)

### 1.2 기존 프로그램의 한계 (= 웹 ERP의 명분)

- 매크로(VBA) 보안 차단 해제 등 설치·설정 진입장벽
- 단일 파일 = 단일 사용자, 백업/공유/버전관리 어려움
- 매년 세법·서식 변경 시 파일 재배포 필요

### 1.3 웹 ERP 목표
- 크로스플랫폼(웹/모바일 브라우저), 로그인 기반 **다중 사용자 SaaS**
- 사용자별 다중 사업장·다중 소득 지원 (제도상 사업장별·소득별 장부 분리 필수)
- 입력 → 집계(영업현황표) → **종합소득세 신고서식 자동 생성**까지 파이프라인 유지
- 서버 배포로 세법/서식 갱신을 일괄 반영

## 2. 도메인 개요 (간편장부 제도)

- **대상자**: 회계지식 없는 영세사업자. 직전연도 수입금액 기준
  - 도·소매/농림어업/광업 등: 3억원 미만
  - 제조·음식·건설·운수·정보통신 등: 1.5억원 미만
  - 부동산임대·서비스업 등: 7,500만원 미만
  - 단, 전문직(의사·변호사·회계사·세무사 등)은 수입 무관하게 **대상 아님**
- **작성 원칙**
  - 사업장이 2개 이상이면 사업장별로 각각 작성
  - 소득종류(사업소득 / 부동산임대 소득 등)가 2개 이상이면 각각 작성
  - 증빙서류(세금계산서·계산서·신용카드·현금영수증 등) 기준으로 작성, 장부·증빙 **5년 보관**
- **장부 1행 표준 구조 (국세청 서식 8개 열)**

  `① 일자 · ② 계정과목 · ③ 거래내용 · ④ 거래처 · ⑤ 수입(금액/부가세) · ⑥ 비용(금액/부가세) · ⑦ 사업용 유·무형자산 증감(금액/부가세) · ⑧ 비고(증빙)`

## 3. 데이터 모델 (프로그램 시트 역설계)

### 3.1 계정과목 체계 (`정보` 시트)
- **수입(대분류)**: 매출 / 기타(수입)
- **비용(대분류)**: 상품매입, 재료매입, 제조노무비, 제조경비, 급료, 제세공과금,
  임차료, 지급이자, 기업업무추진비, 기부금, 감가상각비, 차량유지비,
  지급수수료, 소모품비, 복리후생비, 운반비, 광고선전비, 여비교통비, 기타(비용)
- **사업용 자산(유·무형)**: 건물및구축물, 차량운반구, 비품, 기계장치, 기타

### 3.2 증빙유형(비고) — 부가세 자동계산의 키
세금계산서 / 계산서 / 신용카드 / 현금영수증 / 간이영수증 / 기타
> **핵심 규칙**: 부가세는 사용자가 직접 입력하지 않고, 입력 금액(공급가액)과
> 증빙유형(비고)에 따라 **자동 계산**된다. (원본 프로그램의 핵심 자동화 로직)

### 3.3 거래처 (`대량등록_거래처` 시트)
- 거래처 상호 (필수, 중복불가)
- 사업자등록번호 (필수, 중복불가)
- 연락처

### 3.4 사업용 자산 / 감가상각 (`내자산관리` 시트)
- 자산종류, 자산명, 취득일, 취득금액, 처분일, 처분금액
- 감가상각방법(정률법/정액법), 내용연수, 상각률
- 감가상각누계액(전기), 당기 감가상각비, 감가상각누계액, 감가상각비 한도액
- 참조표 내장: `내용연수별상각률`, `표준산업분류연계표`(업종코드↔내용연수 연계)

## 4. 기능 요구사항 (설명서 목차 기반)

### 4.1 기본사항
- **내 정보 관리**: 사업자(성명·생년월일·연락처) + 사업장(상호·소재지·사업자번호·업종·주업종코드·소득종류·제조업여부)
- **거래처 관리**: 등록 / 수정·삭제 / **CSV 파일 일괄 업로드**

### 4.2 장부관리
- **개별 입력**: 거래 건별 입력 (날짜·계정과목 대/소·거래내용·거래처·금액·증빙유형)
- **파일 업로드**: 양식(CSV/엑셀)에 맞춰 일괄 입력, 처리결과 표시
- **수정 / 삭제 / 복사입력**: 매월 반복 거래(임차료·이자 등)를 복사하여 일부만 수정 입력

### 4.3 출력·리포트
- **장부**: 국세청 표준 8열 서식 출력 (기간 필터)
- **영업현황표**: 월별·분기별 수입/비용/자산 증감 집계 (`분석`·`통계` 시트)
- **자산대장**: 사업용 자산 등록 + 감가상각비 계산·출력
- **신고서식(종합소득세)** — 장부 내용 자동 반영:
  - 간편장부 소득금액계산서
  - 총수입금액 및 필요경비명세서
  - 감가상각비 조정명세서 (정률법 / 정액법)

## 5. 웹 ERP 아키텍처 (CodeIgniter 4)

### 5.1 멀티테넌시 (SaaS)
- 사용자 인증: 로그인/회원가입 (예: CodeIgniter Shield)
- 격리 단위: `user → business(사업장) → ledger`
- 모든 조회/집계 쿼리에 `user_id` + `business_id` 스코프 강제 (데이터 격리)
- 과세연도(귀속연도) 파라미터로 장부/서식 분리

### 5.2 데이터베이스 스키마 (초안)
| 테이블 | 주요 컬럼 | 설명 |
|---|---|---|
| `users` | id, email, password_hash, … | 인증 (Shield) |
| `businesses` | id, user_id, 상호, 소재지, 사업자번호, 업종, 주업종코드, 소득종류, 제조업여부 | 사업장(테넌트 하위 단위) |
| `partners` | id, business_id, 상호, 사업자번호(UNIQUE), 연락처 | 거래처 |
| `accounts` | id, 구분(수입/비용/자산), 대분류, 소분류 | 계정과목 (시드) |
| `ledger_entries` | id, business_id, 귀속연도, 일자, account_id, 거래내용, partner_id, 공급가액, 부가세, 증빙유형, 유형(수입/비용/자산) | **핵심 거래 테이블** |
| `assets` | id, business_id, 자산종류, 자산명, 취득일/금액, 처분일/금액, 상각방법, 내용연수, 상각률, 상각누계액 | 사업용 자산 |
| `depreciation_rates` | 내용연수, 정률, 정액 | 상각률 참조 (시드) |
| `industry_codes` | 코드, 업종명, 연계 내용연수 | 표준산업분류 (시드) |

> 보안: 사업자번호·연락처 등 개인정보 취급. `CLAUDE.md` 보안규칙 준수
> (입력검증 `$this->validate()`, 출력 `esc()`, Query Builder, POST폼 `csrf_field()`).

### 5.3 서비스 로직 (VBA → PHP Service 계층으로 이전)
- `VatCalculatorService` — 증빙유형 기반 부가세 자동계산
- `LedgerImportService` — CSV/엑셀 일괄 업로드 + 검증·처리결과
- `SummaryService` — 월/분기 집계(영업현황표)
- `DepreciationService` — 정률/정액 감가상각 계산
- `TaxFormService` — 소득금액계산서·필요경비명세서·감가상각조정명세서 생성
- 컨트롤러는 얇게, 비즈니스 로직은 Service/Model에 위치 (CI4 규약)

### 5.4 화면(라우트) 구성
```
/auth/*                     로그인·회원가입
/businesses                 사업장 목록/선택
/settings/profile           내 정보 관리
/partners                   거래처 관리 (+ CSV 업로드)
/ledger                     장부 목록/조회 (기간·계정 필터)
/ledger/create              개별 입력
/ledger/import              파일 업로드
/assets                     자산대장 / 감가상각
/reports/summary            영업현황표
/reports/tax-forms          신고서식(종합소득세) 생성·출력
```

| 단계 | 범위 | 산출물 |
|---|---|---|
| **0. 기반** | CI4 프로젝트 세팅, 인증(Shield), 멀티테넌시 골격, 계정과목/상각률 시드 | 마이그레이션·시드 |

## 7. 리스크·검토 필요 사항
- **세법 정확성**: 부가세 자동계산 규칙, 감가상각 한도, 소득금액 계산식은 국세청 로직과 **정확히 일치**해야 함 → VBA 수식 상세 추출로 별도 검증 필요
- **귀속연도별 서식 차이**: 서식은 매년 변경 → 연도별 템플릿 버전 관리 설계 필요
- **개인정보/보안**: 사업자번호 등 취급, 접근제어·암호화·감사로그 검토
- **출력 형식**: PDF/엑셀 다운로드 시 국세청 제출 서식과 레이아웃 일치 여부
- **원본 프로그램은 부가세 신고 도구가 아님**: 종합소득세 장부·신고 보조 도구 범위 명확화
